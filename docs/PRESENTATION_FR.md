# Génomique comparative virale en R

**Question / objectif :** Étudier la concordance entre distances de génomes et genres taxonomiques sur 29 génomes de bactériophages.

**Candidatures concernées :** Génomique, computational biology, développement R, ingénierie de recherche.

**Preuves consultables :** Package R testé, analyse MAFFT/DECIPHER, métriques et contrôles package/analyses en CI.

**Limites :** Deux genres seulement ; accord du plus proche voisin interne au panel. Arbre Neighbor-Joining exploratoire, pas de classification externe.

Consulter le README pour les commandes, l’origine des ressources et les résultats. La présence de tests ou d’une CI ne valide pas à elle seule les conclusions scientifiques.
